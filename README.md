# 🧬 My First Biopython Project

Welcome to my very first Bioinformatics project! I am a beginner developer exploring the world of DNA and coding.

## 🚀 What does this project do?
This project uses the **Biopython** library to analyze a DNA sequence. It automatically calculates:
* **The Partner DNA Strand** (Reverse Complement)
* **The RNA Copy** (Transcription)

## 💻 Tech Stack
* **Language:** Python 🐍
* **Library:** Biopython 🧪
* **Platform:** Google Colab ☁️
